# 数据湖治理配置中心

离线版数据湖治理配置工具，涵盖多源接入通道、分层表结构设计、湖区分区策略、流批转换编排、元数据编目检索与资源计量管理，所有配置持久化到浏览器本地存储。

这是一个**纯前端**管理平台：React + Vite + TypeScript，仓库里没有后端服务。业务数据由
`frontend/src/data/` 下的本地数据层提供：首次打开用示例数据播种，之后的登记、筛选与状态流转
结果都持久化在浏览器 `localStorage` 里，刷新或重开浏览器都还在。dev server 已关掉自动打开页面，
启动后按终端打印的地址手工打开。

## 目录结构

```text
.
├── frontend/                 React + Vite + TypeScript 前端（唯一运行单元）
│   ├── src/views/            每个业务模块一个页面
│   ├── src/api/local-service.ts   本地数据服务：列表、筛选、动作流转、导出
│   ├── src/data/             模块元数据 / 示例数据 / localStorage 持久化
│   ├── src/stores/           会话与筛选状态
│   └── vite.config.ts        dev server 配置（open: false，无 /api 代理）
├── .gitignore
└── docker-compose.yml
```

## 启动

```bash
cd frontend
npm install
npm run dev
```

前端默认监听 `http://127.0.0.1:5173/`，dev server 不会自动打开浏览器，需要自己访问。

生产构建：

```bash
cd frontend
npm run build
```

## 约定

- 每个模块的页面在 `frontend/src/views/<模块>/index.vue`，页面只负责渲染，读写统一走
  `frontend/src/api/local-service.ts`。
- 字段、状态、动作与流转目标集中在 `frontend/src/data/modules.ts`；示例数据在
  `frontend/src/data/seed.ts`。
- 状态流转只允许在 `local-service.ts` 里改，页面组件不做业务判断。
- 想回到初始数据：清掉浏览器里 `lake-govern-config:entries` 这一项，或调用 `resetModule(模块)`。

## 数据编目的状态机与目录-元数据一致性

数据目录的动作不再走通用的目标态改写，统一收口在
`frontend/src/api/catalog-service.ts`，沿「目录动作 → 元数据同步 → 历史版本 → 导出」这条数据流处理：

- **单向状态机**：只允许 `草稿 → 待审核 → 已发布 → 已废弃`。已发布目录不能再用「提交审核」
  回退，已废弃是终态；不允许的动作在服务层直接拒绝（按钮置灰只是辅助，不是唯一闸门）。
- **目录版本与修订号**：每次动作生成新版本号 `编目编号-v修订号`，行内带 `_revision` 乐观锁。
  页面提交时回传当前修订号，连续点击或两个管理员同时提交时，旧修订号的请求冲突失败、
  同目录在途请求由在途锁拒绝，只留下一个有效结果。
- **元数据同事务同步**：发布目录时随版本写入一条「已生效」属性条目（元数据模块的结果），
  旧生效条目作废保留；废弃目录时关联生效条目全部作废，行数据与历史版本不删除。
- **事务与回滚**：目录、元数据、历史版本先在内存草稿里算完，再一次性落盘；任一步写入失败，
  内存与 `localStorage` 都恢复到操作前，临时审核结论随草稿丢弃。
- **提交后校验**：提交后逐项核对清单状态、编目版本、元数据条目版本与历史流水，缺哪一步就
  报哪一步，不靠刷新掩盖；`verifyCatalogConsistency()` 也在页面加载与导出前执行，校验不过
  会阻止导出并在页面横幅列出问题。
- **历史版本**：目录每次动作向 `lake-govern-config:catalog-history` 追加一条只增不改的快照
  （含当时同步的元数据条目），页面「查看历史」可追溯。
- 内部字段统一以下划线开头（`_revision`、`_catalogId` 等），不进页面列与导出 CSV。
- 验证脚本：`cd frontend && npm run verify`，覆盖状态机、并发冲突、元数据同步、废弃闭环、
  事务回滚与导出一致性共 15 项检查。
